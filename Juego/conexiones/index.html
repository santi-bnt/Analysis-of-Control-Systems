UART signals use 3.3 V logic. GPIO17 has a different role on each board.

Startup behavior

X: finds the switch, stops, and sets 0 mm. Timeout: 60 s. It then accepts position commands.

Y: automatic homing using the NC switch on GPIO15 (60 s timeout). The switch establishes the Y-axis zero.

04 / BOARD SENSING

LDR array · 3 × 3

Array coordinates: row 0 = minimum Y; column 0 = minimum X. Use each module’s AO output; DO is unused.

X increases to the right →
Rows 0, 1, and 2 correspond to increasing Y.

One block per sensor

3.3 V → LDR module VCC*
Common GND → module GND
AO → GPIO assigned to its cell

*Use LDR modules compatible with a 3.3 V supply. AO must remain within the ESP32-S3 input voltage range.

GPIO1–10 belong to ADC1; GPIO11 and GPIO13 belong to ADC2. Each sensor uses its own ambient baseline: detection requires a drop greater than 70 ADC counts for 10 readings. Adjust with t <drop> over USB serial (115200 baud).

05 / POWER AND COMMON GROUND

Power distribution

Motor power supply

Motor +V → B+ on both BTS7960 drivers
Motor −V → B− on both BTS7960 drivers

Choose the supply voltage to match the motor rating and driver range. Each M+/M− pair connects to its respective motor.

Regulated logic supply

Regulated 5 V → VCC on each BTS7960*
USB / supported power input → each ESP32 board

*Reference: Handsontec IBT-2 module, 5 V VCC and 3.3–5 V control inputs. Check your module variant. Keep motor supply voltage away from logic VCC and GPIO pins.

Common ground bus

Supply − · B− X/Y · BTS X/Y GND · ESP32 GND · S3 GND · encoder GND · LDR GND · switch COM

All blocks share the same ground reference. Route motor current returns to the supply rather than through the ESP32 boards or signal wires.
